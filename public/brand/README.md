## Como converter para PNG
1. Acesse https://cloudconvert.com/svg-to-png
2. Faça upload do SVG
3. Configure largura desejada (ex: 512 para perfil Instagram)
4. Converta e baixe

## Tamanhos recomendados por uso
- Favicon: 32x32, 64x64
- Google Meu Negócio: 720x720 mínimo
- Instagram perfil: 320x320
- LinkedIn perfil: 300x300
- Assinatura email: 200x60 (horizontal)
- Cartão de visita: 300 DPI (qualquer tamanho)
