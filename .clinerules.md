# Regras Obrigatórias do Projeto Primex Sistemas

## Ambiente
- Sistema operacional: Windows
- Shell: PowerShell (NUNCA usar comandos Unix como ls -la, &&, /dev/null, sed, grep)
- Para listar arquivos: usar `Get-ChildItem`
- Para mudar de pasta: usar `Set-Location`
- Para encadear comandos: usar `;` (ponto e vírgula), NUNCA `&&` ou `||`
- Para redirecionar erros: usar `2>$null`, NUNCA `2>/dev/null`

## Contexto do Projeto
- Nome: Primex Sistemas
- Tipo: Site institucional corporativo
- Empresa: Desenvolvimento de softwares e soluções inteligentes
- Lema: "Soluções Inteligentes"
- Cores: Verde (#00C853) e Preto (#0A0A0A)
- Logo: deve ser criada do zero (SVG) em verde e preto
- Este é um projeto NOVO, do zero, em pasta vazia

## Stack Técnica
- Framework: Next.js 15 (App Router) + TypeScript
- Estilo: Tailwind CSS v4 + shadcn/ui
- 3D: React Three Fiber + @react-three/drei + @react-three/postprocessing
- Animação: GSAP + Framer Motion
- Ícones: lucide-react
- Deploy: Vercel

## Qualidade
- Todo componente tipado (props + retorno)
- Componentes 3D isolados em `src/components/three/`
- Hooks em `src/hooks/` com testes
- Commits semânticos: feat:, fix:, chore:, refactor:
- Código comentado com JSDoc nos pontos críticos
